# The Smokepit

The source of The Smokepit, a Markdown blog whose themes take their palettes, lettering styles and shapes from US cigarette pack design. A first visit gets a random theme, and readers can switch to explore the rest. No brand names or logos: each theme signals its pack without copying it.

Built with Hugo, hosted on Netlify, on the plumbing of Turrible Takes (`bad-blog`, archived). Start with [AGENTS.md](AGENTS.md) and [docs/INTENT.md](docs/INTENT.md).

*Status: phase 2 done. Full Flavor, Menthol Stripe and Sun Cured are built, passed the owner's review, and are live. Next: more packs.*
